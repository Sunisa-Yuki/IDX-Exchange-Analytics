# IDX Exchange MLS Analytics Internship

## Overview

12-week data analytics internship focused on residential real estate market analysis using MLS transaction data. (Spring 2026)

## Technologies

- Python
- Pandas
- Tableau
- Git/GitHub

## Project Objectives

- Aggregate monthly MLS datasets
- Perform exploratory data analysis
- Clean and validate transaction data
- Engineer housing market metrics
- Detect and flag outliers
- Build interactive Tableau dashboards
- Generate market intelligence reports

## Deliverables

### Market Analysis Dashboard
- Median Home Price Trends
- Days on Market
- Close-to-List Ratio
- New Listings
- Closed Sales

### Competitive Intelligence Dashboard
- Top Agents
- Top Brokerages
- ZIP Code Heat Maps
- Market Performance Metrics
